# Seedyn design context

## Audience

David and a small invite-only group of technical users. They upload files often,
copy durable public links, and may automate the same flow with scripts, API keys,
or ShareX.

## Primary jobs

- Upload a local file or ingest an HTTPS URL from the browser.
- Find a stored object and copy its permanent public URL quickly.
- Inspect, convert, or delete an object without ambiguity.
- Create scoped credentials for any HTTP client; ShareX is one supported client.
- Read protected API, serving, integration, and operations documentation.

## Personality

Precise personal utility: warm, tactile, compact, quiet, and trustworthy. The
working visual idea is **Paper Shelf**—paper and ink neutrals, hairline rules,
file-native density, and one ember accent. It should feel like a well-made
desktop file tool, not a generic SaaS dashboard or a marketing gallery.

## Visual constraints

- Deliberately distinct from DavidApps Auth: no cool cyan-on-charcoal identity,
  no centered auth-card grammar across the product, and no recolor-only fork.
- System light and dark themes; no manual theme switch.
- One primary filled action per screen. Prefer rules and spacing to nested cards.
- Restrained motion only for direct feedback; repeated navigation remains instant.
- Product UI is dense and scan-friendly; documentation keeps a comfortable
  reading measure through real Fumadocs layout and page primitives.
- ShareX never occupies a product heading, subtitle, empty state, or nav label.

## Voice

Direct and literal. Lead with upload, store, serve, copy, and permanence. Avoid
startup language, inflated promises, and treating implementation details as the
product. Explain public-by-link access plainly whenever it affects a decision.

## Accessibility and quality bar

Keyboard complete, visible focus, WCAG AA text contrast, 44px touch targets,
usable at 360px and 200% zoom, reduced-motion aware, and correct in both colour
schemes. Browser verification must cover CSS-loaded computed styles as well as
semantic content.
