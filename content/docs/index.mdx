---
title: Seedyn
description: Private-by-account uploads with public-by-link media URLs.
---

Seedyn accepts screenshots, files, text, and short media from ShareX or the
browser. It stores the original in a private MinIO bucket and returns an
unguessable public URL on `i.dave.tips`.

## Start here

1. Sign in with DavidApps.
2. Create an API key with the upload scopes you need.
3. Download the generated ShareX custom uploader while the key is still visible.
4. Import the `.sxcu` into ShareX and send a test capture.

The API key is shown once. Seedyn stores only its SHA-256 digest, so a lost key
must be revoked and replaced.

## Two origins, one application

- `seedyn.dave.tips` contains authenticated pages, docs, and upload APIs.
- `i.dave.tips` serves exact public media URLs with no cookies or directory listing.

Both origins reach one Next.js deployment. The media boundary is enforced by
host routing and repeated inside the media handler.
